Implementasi Infrastruktur Blog Berbasis Container pada Home Server Menggunakan CasaOS dan Cloudflare Tunnel

Project ini bertujuan untuk mengimplementasikan blog self-hosted berbasis container pada STB HG680P menggunakan CasaOS. Dengan dukungan Cloudflare Tunnel, server lokal dapat diakses secara aman melalui domain publik ber-SSL, sehingga perangkat sederhana dapat berfungsi sebagai home server hemat biaya sekaligus sarana belajar self-hosting.

Proyek ini mengimplementasikan blog self-hosted pada STB HG680P berbasis Armbian dengan memanfaatkan CasaOS sebagai platform manajemen container. Proses deployment dilakukan menggunakan Docker dengan Nginx untuk menjalankan website statis. Akses publik disediakan melalui Cloudflare Tunnel, sehingga blog dapat diakses menggunakan domain ber-SSL tanpa perlu IP publik atau konfigurasi firewall yang rumit.

Dengan konfigurasi ini, STB HG680P dapat dimanfaatkan sebagai home server hemat biaya yang mendukung praktik self-hosting, pengelolaan file sederhana, serta dapat dikembangkan menjadi lab pribadi untuk pembelajaran DevOps maupun keamanan jaringan.

Kelebihan Deployment Ini

  • Hemat biaya.
  • Daya rendah, efisien 24/7.
  • Mudah dikelola via CasaOS.
  • Fleksibel dengan Docker.
  • Akses aman via Cloudflare + SSL.
  • Tanpa IP publik & port forwarding.
